# v1.0.0 Release Notes / 发布说明

## 中文

首个GitHub公开版，包含南风H3多参视频生成V4、南风提示词列表、双语文档和已脱敏工作流。模型权重不包含在下载包内。

下载`nanfeng-h3-comfyui-v1.0.0.zip`，将其中`nanfeng_prompt_nodes`复制到`ComfyUI/custom_nodes/`，重启后导入附带工作流。

## English

First public GitHub release with NanFeng H3 Multi-Reference Generator V4, NanFeng Prompt List, bilingual documentation, and a sanitized workflow. Model weights are not included.

Download `nanfeng-h3-comfyui-v1.0.0.zip`, copy `nanfeng_prompt_nodes` into `ComfyUI/custom_nodes/`, restart ComfyUI, and import the included workflow.
