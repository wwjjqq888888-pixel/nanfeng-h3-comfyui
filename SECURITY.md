# Security / 安全说明

Never commit or publish `.env`, `.audio-drive.env`, API keys, tokens, vision-analysis caches, local media, model weights, generated bytecode, or test caches.

禁止提交或发布 `.env`、`.audio-drive.env`、API Key、Token、视觉分析缓存、本地媒体、模型权重、字节码或测试缓存。

V10 keeps regular storyboard credentials server-side in `nanfeng_prompt_nodes_v10/.env`. Audio-drive credentials are isolated in `nanfeng_prompt_nodes_v10/.audio-drive.env`. Workflow JSON and frontend configuration responses do not expose key values. Use `.env.example` only as a public template.

V10 的常规智能分镜凭据保存在节点目录服务端 `.env`，智能音频驱动凭据独立保存在 `.audio-drive.env`。工作流 JSON 和前端配置响应不会返回密钥值；公开发布仅使用 `.env.example` 模板。

When reporting a security issue, do not attach live credentials, private media, or proprietary model weights. Describe the affected route/file, reproduction steps, expected behavior, and ComfyUI/Python versions.
